# 쿠팡 로켓 운영 대시보드 (수강생용)

신규 상품 수집 · 발주확정/쉽먼트 업로드 · 발주서 만들기를 한 화면에서 실행합니다.

## 설치 (처음 한 번)
1. [파이썬](https://www.python.org/downloads/)을 설치합니다. 첫 화면의 **Add python.exe to PATH**를 꼭 체크하세요.
2. PC에 Chrome이 설치되어 있어야 합니다.
3. `1_설치.bat`을 더블클릭합니다.

## 실행
- `2_대시보드_실행.bat`을 더블클릭하면 브라우저에 `http://127.0.0.1:5080`이 열립니다.
- 검은 창을 닫으면 대시보드가 꺼집니다.

## 처음 설정
1. 강사가 공유한 **운영 시트 템플릿**을 *파일 → 사본 만들기*로 내 드라이브에 복사합니다.
2. 구글 드라이브에 `INBOX`, `쉽먼트` 폴더를 만듭니다.
3. 대시보드 **설정** 탭에 시트 주소와 두 폴더 주소를 붙여 넣고 저장합니다.
4. 왼쪽 아래 **허브 Chrome 열기** → 뜬 Chrome에서 쿠팡 서플라이어 허브와 구글에 로그인합니다.
   (로그인은 이 폴더의 `chrome_profile`에 저장되며, 평소 쓰는 Chrome과 따로 동작합니다.)

## 바코드·라벨 앱 (웹)
- 대시보드의 **바코드·라벨 앱** 버튼을 누르거나, 강사에게 받은 주소로 들어갑니다.
- 강사에게 받은 **아이디/비밀번호**로 로그인 → **⚙️ 설정** 탭에서 내 운영 시트 주소, 택배 양식, 라벨 문구를 저장합니다.
- 설정 화면에 나오는 이메일에 내 시트를 **편집자**로 공유하세요. 한 번 저장하면 다음 로그인에도 그대로입니다.

## 업데이트
- `3_업데이트.bat`을 실행합니다. 내 설정·로그인·수집 파일은 그대로 둡니다.
- 버전은 화면 왼쪽 위와 `VERSION` 파일에서 확인합니다. 바뀐 내용은 `CHANGELOG.md`에 있습니다.
